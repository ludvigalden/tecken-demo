# Security policy

## Supported versions

| Version | Supported                                  |
| ------- | ------------------------------------------ |
| 0.x     | Yes, the latest published 0.x release only |

This is a demonstration project. It handles no accounts, no personal
data and no secrets in the client, but reports are still taken seriously.

## Reporting a vulnerability

Please report privately. Do not open a public issue.

- **Preferred:** GitHub private vulnerability reporting, under the
  repository's **Security** tab → **Report a vulnerability**.
- **Email:** [tecken-demo@ludvigalden.com](mailto:tecken-demo@ludvigalden.com), with "tecken-demo security" in the subject.

Include what you found, how to reproduce it, and what an attacker could
do with it.

## What to expect

- An acknowledgement within 5 working days.
- An assessment and, where a fix is needed, a planned fix date within 14
  days of the acknowledgement.
- Credit in the release notes if you want it.

The design and its known limits are described in
[docs/security/threat-model.md](docs/security/threat-model.md).
