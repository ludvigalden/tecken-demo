# Open-source checklist (DIGG)

Checked against DIGG's publication checklist for open-source software, the
handbook that accompanies the "Policy och riktlinjer för anskaffning,
utveckling och publicering av öppen programvara". Tecken is not
published by an authority, but it follows the checklist as if it were.
Every row is either met (✓) or has a stated reason.
